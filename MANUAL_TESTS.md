# MANUAL_TESTS — Map Screen

Surface chosen: **Map screen** (hamburger menu, Help button, Filter / Vehicle list / Find-me FABs, and their downstream screens).

21 cases. Categories covered: functional, non-functional, accessibility, localization, permission.

**Disposition legend:**
- `auto-later` — worth automating once the framework supports the prerequisite (test data control, permission flags, etc.)
- `manual-only` — non-functional or human-judgement check; automation is a poor fit
- `depends` — could be automated but cost/value ratio is questionable
